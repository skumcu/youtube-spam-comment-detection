# YouTube Spam Comment Detection

## Project Overview

This project aims to classify YouTube comments as **spam** or **non-spam** using a machine learning model.

The project includes data preprocessing, text vectorization, model training, and prediction using the Bernoulli Naive Bayes algorithm.

## Dataset

The dataset contains YouTube comments labeled as either spam or non-spam.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn

## Machine Learning Model

- CountVectorizer
- Bernoulli Naive Bayes
- Train/Test Split
